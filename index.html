✅ SeriouslyPrivateChecklist

A seriously private, serverless checklist you share with a simple link.

  • 📝 No account.
  • 🌐 No server.
  • 🕵️ No tracking.

Projected features

  • Markdown task lists — - [ ] buy milk → - [x] buy milk, marked done ✅.
  • Share by URL — the list is encoded into the URL fragment (#…), which is never sent to any server.
  • Optional end-to-end-encrypted sharing — passphrase-encrypted links (AES-256-GCM via WebCrypto).
  • URL-only storage — no cookies, no localStorage; behaves identically in private navigation.
